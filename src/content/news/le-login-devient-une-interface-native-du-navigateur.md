---
title: Le login devient une interface native du navigateur
date: 2026-11-02
summary: Google rapproche mots de passe et passkeys dans une interface de
  sélection d'identifiants gérée par le navigateur.
---
Plutôt que de demander à l'utilisateur de choisir systématiquement entre plusieurs méthodes, le navigateur peut présenter les identifiants disponibles dans une interface commune.

Le site conserve les parcours alternatifs lorsque l'utilisateur ne possède aucun identifiant local.

Impact UX : la page de login devient progressivement un mécanisme de secours et de découverte, plutôt que l'unique point d'entrée.

Cette évolution est particulièrement intéressante pour les applications où les utilisateurs reviennent régulièrement.
