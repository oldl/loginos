---
title: Le QR code devient un fallback, pas le parcours privilégié
date: 2026-11-15
summary: Les recommandations UX sur les passkeys privilégient les identifiants
  synchronisés, tout en conservant les QR codes pour les connexions entre
  appareils.
---
Les recherches utilisateur publiées par Passkey Central montrent une préférence pour les passkeys synchronisées, plus simples que le parcours QR code. Ce dernier reste important sur les ordinateurs partagés ou lorsqu'aucune passkey n'est disponible localement.

Impact UI : privilégier le chemin le plus court, avec une option « Utiliser un autre appareil » visible et compréhensible.

<https://www.passkeycentral.org/design-user-journeys/optional-patterns/cross-device-sign-in>
